一、产品原则（讲解用）

原则 1 陪伴优先 不做多模型工作台；用户零配置
原则 2 安全底线 儿童更严；危险话题温和转开
原则 3 记得你 昵称与喜好可延续到下次招呼
原则 4 温暖不越界 可树洞；明确不做恋爱角色
原则 5 零门槛 无登录、无 API Key、无温度旋钮
非目标 刻意不做 RAG 工作台 / 家长同意（二期）/ 语音（二期）
