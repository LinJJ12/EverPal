# 界面 Demo（纯 HTML）

多页卡通演示，**不接大模型**，用于讲流程与界面切换。

## 打开方式

用浏览器打开：

`demo/index.html`

或进入目录后双击任意页面。顶部深色条可在各页之间跳转。

## 页面

| 文件 | 内容 |
|------|------|
| `index.html` | 演示导览（推荐入口） |
| `welcome.html` | 欢迎 / 品牌开场 |
| `mode.html` | 儿童 / 成人模式 |
| `nickname.html` | 昵称（可跳过） |
| `companions.html` | 小暖 / 跳跳 / 阿茶 |
| `chat.html` | 聊天 + 话题卡片 + 模拟回复 |
| `settings.html` | 本地设置（无登录、无模型配置） |

共享资源：`css/cartoon.css`、`js/store.js`（localStorage 记住选择）。
