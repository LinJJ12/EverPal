# 侧栏继续上次会话

## Goal

换伙伴后默认仍是**新空白聊**；若该伙伴本机有上次会话指针，侧栏提供 **「继续上次」** 一键恢复，无需绕历史月历。

## Requirements

1. 切换伙伴时：保存离开伙伴的当前 `sessionId`（若有）到 `jiuban_sessions_by_companion`；**不清掉**目标伙伴已有指针；UI 进入空白新聊（不自动加载）。
2. 当前伙伴存在可恢复指针、且当前屏为空聊（无 `sessionId` / 无消息）时，侧栏显示「继续上次」。
3. 点击「继续上次」→ `loadSessionById` 恢复该会话（与历史月历进房同路径）。
4. 「新建对话」仍清除**当前**伙伴指针 + 空白屏（服务端历史保留）。
5. 指针失效（404）时友好提示并清掉该指针。

## Acceptance Criteria

- [x] A→B→回到 A：默认可新聊；点「继续上次」能回到离开 A 前的线程
- [x] 无上次指针时不显示「继续上次」
- [x] 「新建对话」后该伙伴不再显示「继续上次」（直至又聊出新 session）
- [x] 不经过 `/history` 也能完成恢复

## Out of Scope

- 切换时自动加载上次会话
- 侧栏完整会话列表 / 多设备同步
