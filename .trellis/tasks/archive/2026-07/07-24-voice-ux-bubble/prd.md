# 语音交互：点按说话与气泡朗读

## Goal

网页端语音更好用：说话改为**点按开关**（非按住）；朗读放在**每条助手回复下方**，只读该条。

## Requirements

- R1：composer 语音按钮改为「点我说话 / 说完了」；去掉按住手势依赖。
- R2：移除工具栏全局「朗读回复」；每条完成的助手气泡下有「朗读 / 停止朗读」。
- R3：朗读仅该条文本；切换条目或流式开始时停止当前朗读。

## Acceptance Criteria

- [x] AC1：点按即可开始/结束识别，文案与状态清晰。
- [x] AC2：工具栏无全局朗读；助手回复下可见朗读按钮。
- [x] AC3：点击某条只读该条，不会读全部历史。

## Out of scope

- 云端 STT/TTS、自动朗读
