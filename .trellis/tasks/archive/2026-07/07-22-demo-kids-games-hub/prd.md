# Demo 益智小游戏大厅（7 款）

## Goal

在纯 HTML `demo/` 中新增「益智小游戏」大厅与 **7 款**可玩本地小游戏，供儿童选择游玩；视觉与玖伴卡通 Demo 一致；零登录、离线、不接外链游戏、不接真实大模型。

## Background

- 壳：`demo/*.html` + `demo/js/store.js` + `demo/css/cartoon.css`；状态键 `companion_demo_v2`。
- 顶栏：`NAV_PRIMARY` + `NAV_MORE`；讲解路径 `TOUR_STEPS`（10 步）目标时长约 8–12 分钟。
- 硬规则：卡通、手机优先、大点击区；无登录 / 无模型配置 UI。
- 并行任务 `07-22-demo-frontend-polish` 与本任务正交，不互相阻塞。
- 「重置演示」：`DemoStore.resetDemo()` 全量写回 defaults。

## Decisions

| 决策 | 结论 |
|------|------|
| 清单 | 贪吃蛇、2048、扫雷、五子棋、俄罗斯方块、数字拼图、消消乐（一次做齐） |
| 形态 | 本地 Canvas/DOM + JS；禁止第三方游戏 iframe/外链 |
| 导航 | 顶栏主栏「游戏」→ 大厅；`index.html` 可加入口；**不**进 `TOUR_STEPS` |
| 难度 | 固定儿童向；无可选档位 |
| 成绩 | 本机最高分/最佳纪录；刷新仍在 |
| 五子棋 | 仅人机简单 AI |
| 重置 | 「重置演示」一并清空游戏成绩 |
| 任务结构 | 单任务（大厅 + 7 款） |

## Requirements

- **R-hub**：大厅列出 7 款（名、一句说明、入口）；可展示各游戏本机纪录摘要。
- **R-games**：7 款可开始、游玩、结束/重开；规则可用，能完整打完或明确结束一局；五子棋为人机。
- **R-nav**：`NAV_PRIMARY` 含「游戏」；不写入 `TOUR_STEPS`。
- **R-score**：游玩页展示本局成绩 + 本机纪录；存入 `companion_demo_v2`（或同键扩展字段），随 `resetDemo` 清空。
- **R-skin**：卡通 CSS 变量 + 玖伴顶栏；中文温和文案。
- **R-mobile**：竖屏可玩；触控优先；键盘可为桌面增强。
- **R-offline**：无网络依赖、无第三方游戏页。

## Out of scope

- 难度切换、联网对战、账号排行、内购、必备音效包
- 同机双人五子棋、家长时长锁、真模型陪玩
- 正式 SPA `web/` 迁移；改 `docs/PRD.md` 正文（除非另开需求）

## Acceptance Criteria

- [ ] AC1：大厅页可见全部 7 款入口
- [ ] AC2：7 款均可开始一局并重开；无控制台致命错误
- [ ] AC3：约 ≤480px 宽可完成基本操作
- [ ] AC4：顶栏主栏「游戏」可进大厅；`TOUR_STEPS` 仍为 10 步且不含游戏
- [ ] AC5：无外链第三方游戏页
- [ ] AC6：至少一款破纪录后刷新仍显示更新后的本机纪录
- [ ] AC7：设置页「重置演示」确认后，游戏纪录与档案一并清空
